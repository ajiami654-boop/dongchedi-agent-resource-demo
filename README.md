# 懂车帝差评会话复刻

基于用户提供的三张完整会话截图，制作可独立运行的本地模拟；不调用 Test、不调用模型、不修改线上数据。

在线预览：[GitHub Pages](https://ajiami654-boop.github.io/dongchedi-agent-resource-demo/?scheme=4)。发布仓库：[dongchedi-agent-resource-demo](https://github.com/ajiami654-boop/dongchedi-agent-resource-demo)。发布仓库是本目录的独立静态副本，本目录后续改动需同步过去才能更新在线页面。

## 打开

在仓库根目录执行 `python3 -m http.server 7017 --bind 127.0.0.1 --directory demos/dongchedi-replay`，访问 http://127.0.0.1:7017 。

默认展示截图中的完整回答。顶部会话标题菜单提供「重新播放问答过程」及三个截图位置。新会话或输入框发送也可播放同一固定示例；发送按钮在执行时变成停止按钮。

## 还原范围

- 三张截图的回答原文、工具分组、首次失败与重试成功、车系图表、报告、最终说明。
- 顶栏、输入区、资源树、工具折叠、报告/图表折叠、详情弹层、独立报告滚动。
- 右侧资源列表、顶栏看板图标，以及报告详情顶部的「打开仪表板」均可进入仪表板；点击五个组件显示悬浮操作栏，点击编辑后在右侧原位显示组件编辑器，左侧对话不变。可修改名称、字段、数值、颜色和筛选条件，保存后回到看板。链接加 `view=dashboard` 可直达看板。该部分根据新增截图做静态交互模拟。
- 截图可见车系数值和七类主题数值；原始问答开头与时间推进为模拟补充。
- 前端原始 SVG：`packages/ui/src/icon`、本仓 `@fx-ui/icon` 与兄弟仓 `fx-data-web/node_modules/@fx-ui/icon`。主前端 iconfont 的故事板图标作原始资源提取；不以截图整图代替可交互界面。

## 四种展示方案（2026-10-15）

依据用户上传的《分析Agent过程资源展示形式调研.pdf》增加固定顶部切换条；URL `?scheme=1/2/3/4` 可直接定位，默认方案二。

- 一：保留原始过程完整卡片。
- 二：过程资源缩略图，点击右侧查看；最终报告完整展示。
- 三：仅保留工具记录后的资源链接，不另加按钮，点击右侧查看；最终报告完整展示。
- 四：过程仅保留工具文字与关联入口，答案末尾展示最终报告及默认收起的“本轮创建资源（2）”列表；展开后点击资源在右侧查看。

演示取舍：文档未确定方案四边界，本示例按“本轮实际更新、同资源最新版本”汇总为两项；查找类资源保留原名称入口，不自动变成缩略图。低于20%的回看频率是文档待验证假设，未据此删去回看能力。所有方案共用同一份回答与数据，支持完整回放；并非新增后端实现。
